## Infraestructura Tècnica

### Climatització
- [ ] Aire condicionat instal·lat
- [ ] Temperatura 18-27°C
- [ ] Humitat 30-55%
- [ ] Sensors de temperatura
- [ ] Alertes funcionant

### Protecció contra Incendis
- [ ] Detectors de fums
- [ ] Sistema d'extinció gas inert
- [ ] Dues sortides d'emergència
- [ ] Senyalització clara
- [ ] Pla d'evacuació

### Control d'Accés
- [ ] Porta blindada
- [ ] Sistema de targeta RFID
- [ ] PIN addicional
- [ ] Càmeres CCTV
- [ ] Log d'accés registrat

### Alimentació
- [ ] SAI instal·lat
- [ ] Bateries de 4-8 hores
- [ ] Generador diesel backup
- [ ] Subministrament dual
- [ ] Tests mensuals SAI
